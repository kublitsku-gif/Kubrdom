# Брын — Claude Code skill

Claude Code skill, воспроизводящий **методологию и подачу фитнес-блогера Ярослава
Брына** (YouTube-канал «Ярослав Брын», серия ФМ4М — «Фитнес Модель за 4 Месяца»,
книга «Меняю жир на силу воли»).

Скилл собран из анализа ~16 самых содержательных видео канала (≈117 тыс. слов
транскриптов) по темам: жиросжигание и энергобаланс, метаболизм и метаболическая
адаптация, инсулинорезистентность, гормоны, витамин D, читмил/рефид/диет-брейк,
диетология, спортпит и тренировочные протоколы.

## Что делает

Отвечает на вопросы о похудении, наборе массы, питании (БЖУ), метаболизме,
гормонах, спортпите и тренировках — на строгом **энергобалансе**, с разоблачением
фитнес-маркетинга и в характерном едко-мотивационном тоне Брына.

## Структура

```
.claude/skills/brin/
├── SKILL.md      — персона, «железное ядро» методологии, алгоритм ответа, гид по голосу
└── reference.md  — плотный справочник: формулы калорий, нормы БЖУ, скорость похудения,
                    таблицы читмила/рефида/диет-брейка по % жира, тренировочные диапазоны,
                    дозировки спортпита, разбор гормонов, список мифов и банк цитат
```

## Установка

Скопируй каталог `.claude/skills/brin/` в свой проект (`<project>/.claude/skills/`)
или в пользовательский каталог `~/.claude/skills/`. После этого скилл доступен
в Claude Code — по триггерам («как похудеть», «сушка», «сколько белка», «читмил»,
«сломал метаболизм» и т.п.) или прямым вызовом `/brin`.

## Оговорки

- Методология Брына в целом совпадает с мейнстримом спортивной науки (приоритет
  силовых, дефицит калорий, скепсис к «зоне жиросжигания» и «разгону метаболизма»).
  Это добросовестная популяризация, а не шарлатанство.
- Но исследования он цитирует обезличенно, а местами упрощает и категоричен
  (статины/ЛПНП, «жиры вообще не насыщают», личные протоколы дозирования препаратов).
  Такие места помечены в скилле как спорные.
- **Это не медицинская рекомендация.** По вопросам гормонов, лекарств и здоровья —
  очная консультация специалиста.
